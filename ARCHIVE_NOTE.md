# Compact Archive Scope

This compact bundle supports the Available + Functional evaluation path. It
contains the source, documentation, example inputs, pre-collected data, raw
Figure 6(b-c) logs, plotting and validation tools, and build scripts.

The five paper-scale workload binaries are excluded from this bundle. Their
exact filenames and SHA256 checksums are preserved in
`data/workloads.sha256`. They are needed only for optional paper-scale FDP
hardware experiments, not for the hardware-independent Functional smoke test.
